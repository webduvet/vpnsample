
# Goal

Provide a small, productionish sample backend **reachable only over your VPN** with:

* 2–3 endpoints
* one JSON response
* one PDF response (either generated or static)
* easy to deploy on: EC2 (systemd / docker-compose) or ECS Fargate

Below are two clean options:

---

## Option A — **Single container FastAPI** (JSON + on-the-fly PDF)

**Pros:** one image, minimal infra, generates PDFs dynamically (good for testing latency and payload sizes).
**Cons:** Python image includes LaTeX-like deps if you choose WeasyPrint; here we’ll use the lightweight `reportlab`.

### 1) App code (`app/main.py`)

```python
from fastapi import FastAPI, Response
from pydantic import BaseModel
from typing import Optional
from reportlab.pdfgen import canvas
from reportlab.lib.pagesizes import A4
from io import BytesIO
import os, time

app = FastAPI(title="Sample VPN Backend", version="1.0.0")

class EchoIn(BaseModel):
    message: str
    size_kb: Optional[int] = 0  # extra payload for testing

@app.get("/health")
def health():
    return {"status": "ok", "service": "sample-vpn-backend", "ts": int(time.time())}

@app.post("/api/echo")
def echo(body: EchoIn):
    filler = "x" * (body.size_kb * 1024)
    return {"echo": body.message, "size_kb": body.size_kb, "filler": filler}

@app.get("/docs/meta")
def meta():
    return {
        "service": "sample-vpn-backend",
        "env": {
            "ENV": os.getenv("ENV", "dev"),
            "REGION": os.getenv("REGION", "eu-west-1"),
        },
    }

@app.get("/report.pdf")
def report_pdf():
    # Generate a simple PDF in-memory
    buf = BytesIO()
    p = canvas.Canvas(buf, pagesize=A4)
    w, h = A4
    p.setFont("Helvetica", 20)
    p.drawString(72, h-72, "Sample VPN PDF Report")
    p.setFont("Helvetica", 12)
    p.drawString(72, h-120, "This PDF was generated by FastAPI + reportlab.")
    p.drawString(72, h-140, "Great for testing binary responses over VPN.")
    p.showPage()
    p.save()
    pdf = buf.getvalue()
    headers = {
        "Content-Type": "application/pdf",
        "Content-Disposition": "inline; filename=report.pdf",
        "Cache-Control": "no-store",
    }
    return Response(content=pdf, media_type="application/pdf", headers=headers)
```

### 2) Dependencies (`requirements.txt`)

```
fastapi==0.115.0
uvicorn[standard]==0.30.6
pydantic==2.9.2
reportlab==4.2.5
```

### 3) Dockerfile

```Dockerfile
FROM python:3.12-slim
ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY app ./app
EXPOSE 8080
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8080"]
```

### 4) docker-compose for EC2 (optional)

```yaml
version: "3.9"
services:
  sample:
    build: .
    image: sample-vpn-backend:latest
    container_name: sample-vpn-backend
    environment:
      - ENV=dev
      - REGION=eu-west-1
    ports:
      - "8080:8080"  # keep SG + NACL private (VPN only)
    restart: unless-stopped
```

### 5) Example test calls

```bash
# JSON health
curl -s http://<private-ip>:8080/health | jq

# JSON echo with 256KB payload filler (to test size)
curl -s -X POST http://<private-ip>:8080/api/echo \
  -H 'content-type: application/json' \
  -d '{"message":"hello","size_kb":256}' | jq '.echo, .size_kb, (.filler|length)'

# PDF
curl -s -D- http://<private-ip>:8080/report.pdf -o /tmp/report.pdf
open /tmp/report.pdf
```

## Option B — **Two containers** (JSON API + static PDF via NGINX)

**Pros:** closer to microservice split; one service purely static (fast).
**Cons:** two images/services to manage.

### 1) JSON API (`api/main.py`)

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/health")
def health():
    return {"status":"ok"}

@app.get("/data")
def data():
    return {"customers": 3, "items": [
        {"id":1, "name":"alpha"},
        {"id":2, "name":"bravo"},
        {"id":3, "name":"charlie"},
    ]}
```

### 2) API Dockerfile

```Dockerfile
FROM python:3.12-slim
WORKDIR /app
RUN pip install --no-cache-dir fastapi uvicorn
COPY api ./api
EXPOSE 8080
CMD ["uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8080"]
```

### 3) Static PDF site (NGINX)

Create a `web/static/report.pdf` (any PDF), then:

```nginx
# web/nginx.conf
worker_processes 1;
error_log /var/log/nginx/error.log warn;
pid /var/run/nginx.pid;

events { worker_connections 1024; }

http {
  include       /etc/nginx/mime.types;
  default_type  application/octet-stream;
  sendfile        on;
  keepalive_timeout  65;
  server {
    listen 8081;
    server_name _;
    location / {
      root   /usr/share/nginx/html;
      index  index.html;
    }
    location = /report.pdf { add_header Cache-Control "no-store"; }
  }
}
```

#### NGINX Dockerfile

```Dockerfile
FROM nginx:1.27-alpine
COPY web/nginx.conf /etc/nginx/nginx.conf
COPY web/static /usr/share/nginx/html
EXPOSE 8081
```

### 4) docker-compose (two services)

```yaml
version: "3.9"
services:
  api:
    build: ./
    image: sample-json-api:latest
    container_name: sample-json-api
    ports:
      - "8080:8080"
    restart: unless-stopped

  pdf:
    build: ./
    context: .
    dockerfile: web/Dockerfile
    image: sample-pdf-static:latest
    container_name: sample-pdf-static
    ports:
      - "8081:8081"
    restart: unless-stopped
```

**Endpoints:**

* `http://<private-ip>:8080/health` & `.../data` → JSON
* `http://<private-ip>:8081/report.pdf` → static PDF

## ECS Fargate deployment (one task or two)

You can:

* **Single task, one container** (Option A)
* **Single task, two containers** (Option B)
* **Two tasks behind one internal NLB/ALB** with path routing (`/report.pdf` to PDF container, everything else to API)

### Example task definition (two containers, internal only)

```json
{
  "family": "sample-vpn-backend",
  "networkMode": "awsvpc",
  "cpu": "256",
  "memory": "512",
  "requiresCompatibilities": ["FARGATE"],
  "executionRoleArn": "arn:aws:iam::<acct>:role/ecsTaskExecutionRole",
  "taskRoleArn": "arn:aws:iam::<acct>:role/ecsTaskRole",
  "containerDefinitions": [
    {
      "name": "api",
      "image": "<acct>.dkr.ecr.<region>.amazonaws.com/sample-json-api:latest",
      "portMappings": [{"containerPort": 8080, "protocol": "tcp"}],
      "essential": true,
      "logConfiguration": {"logDriver":"awslogs","options":{"awslogs-group":"/ecs/sample","awslogs-region":"<region>","awslogs-stream-prefix":"api"}}
    },
    {
      "name": "pdf",
      "image": "<acct>.dkr.ecr.<region>.amazonaws.com/sample-pdf-static:latest",
      "portMappings": [{"containerPort": 8081, "protocol": "tcp"}],
      "essential": true,
      "logConfiguration": {"logDriver":"awslogs","options":{"awslogs-group":"/ecs/sample","awslogs-region":"<region>","awslogs-stream-prefix":"pdf"}}
    }
  ]
}
```

### Service (internal)

* Launch in **private subnets** with a **security group** that only allows traffic from your **VPN/Lambda subnet**.
* Place behind an **internal ALB** or **NLB** with a private IP, registered in a private Route53 zone (e.g., `sample.internal`).
* ALB path rules:

  * `/report.pdf` → target group for `pdf:8081`
  * `/*` → target group for `api:8080`

---

## Security Group sketch

* **ECS/EC2 instance SG**: allow inbound **TCP 8080, 8081** **only from** reverse-proxy/Lambda SG and/or VPN client CIDRs. No public ingress.
* **Outbound**: allow to anywhere (or restrict to logging/ECR/VPC endpoints).

```ini
RestartSec=3

[Install]
WantedBy=multi-user.target
```

## Headers & MIME correctness

* JSON endpoints return `application/json; charset=utf-8` (FastAPI handles this).
* PDF endpoint sets `Content-Type: application/pdf` and `Content-Disposition: inline; filename=report.pdf`.
* For NGINX static, ensure `/etc/nginx/mime.types` includes `application/pdf pdf;` (default on Alpine image).

## Which option should you pick?

* **Want simplest?** Option A (single FastAPI container) — fewer moving parts, includes dynamic PDF generation.
* **Want to mirror microservices split or path routing via ALB?** Option B — separate JSON and PDF concerns.
